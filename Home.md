## Why this Matters

Dia Healthcare handles protected health information (PHI) and is subject to HIPAA, SOC 2, and ISO 27001 requirements. A fast, correct response protects patients, preserves our reputation, and keeps us compliant.

## Tip "When in doubt, report it."
    It is always better to report something that turns out to be nothing than to stay silent about something serious.
# What Is a Security Incident?

A **security incident** is any event that threatens the confidentiality, integrity, or availability of company data, systems, or facilities. This includes accidental and intentional actions.

## Examples of security incidents

- A lost or stolen laptop, phone, or USB drive
- A phishing email that was clicked
- Unauthorized access to a patient record
- Malware or ransomware on a company device
- A misdirected email containing PHI
- A vendor reporting a breach on their end
- A stranger in a secure area without a badge

## What is NOT a security incident

| Situation | Where to go instead |
|---|---|
| Forgot your password | Self-service password reset |
| Slow system or application outage | IT Help Desk |
| Printer will not connect | IT Help Desk |
| Cannot access a shared drive | IT Help Desk |
# Types of Security Incidents

| Type | Examples | Who to Notify |
|---|---|---|
| **Phishing / Social Engineering** | Suspicious email, phone call, or text asking for credentials or payment | IT Security |
| **Lost or Stolen Device** | Laptop, phone, tablet, USB drive, badge | IT Security + Manager |
| **Unauthorized Access** | Someone viewing records they should not, sharing passwords, tailgating | IT Security + Compliance |
| **Malware / Ransomware** | Pop-ups, locked files, unusual system behavior | IT Security immediately |
| **Data Spill / Misdirected Email** | PHI sent to the wrong recipient, fax to wrong number | Compliance + IT Security |
| **Physical Security** | Unbadged person in a secure area, propped door, missing files | Facilities + IT Security |
| **Vendor / Third-Party Breach** | Vendor notifies us of a breach affecting our data | IT Security + Compliance |

## Severity levels

| Severity | Definition | Response Time |
|---|---|---|
| **Critical** | Active breach, ransomware, PHI exposure at scale | Immediate (call) |
| **High** | Lost device with PHI, clicked phishing link | Within 1 hour |
| **Medium** | Suspected unauthorized access, misdirected email | Within 4 hours |
| **Low** | Physical security concern, suspicious activity | Within 24 hours |
